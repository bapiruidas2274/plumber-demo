# ClearFlow Plumbing Co. — Website Demo

A responsive front-end website concept for a fictional plumbing company in Brampton, Ontario.

## Files
- `index.html` — page content, metadata, and sample LocalBusiness structured data
- `styles.css` — responsive styling and mobile layouts
- `script.js` — mobile menu, demo quote form interaction, and footer year

## Run locally
Open `index.html` in a modern browser. Internet access is needed for Google Fonts and the remote Unsplash images.

## Before using for a real business
1. Replace the fictional brand, demo phone number, email, service areas, and all sample content.
2. Replace `https://example.com/` and the canonical URL with the real domain.
3. Confirm all services, operating hours, service areas, qualifications, insurance, pricing, and policies with the business.
4. Connect the form to a secure backend or trusted form service, add spam protection, and publish a privacy policy. The current form does not transmit or store submissions.
5. Use properly licensed, locally hosted or approved images and add image credits if required.
6. Validate metadata and LocalBusiness structured data; remove or correct any fields that do not match the real business.
7. This is a static HTML/CSS/JS demo, not a WordPress theme or PHP/MySQL application.
